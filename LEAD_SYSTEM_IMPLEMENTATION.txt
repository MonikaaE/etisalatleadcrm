1. OVERVIEW & OBJECTIVE
--------------------------------------------------------------------------------
The system is built to provide 100% verified, real-world UAE business leads for 
Etisalat B2B telecom sales reps (Closed User Group CUG mobile plans, business SIMs,
broadband, and enterprise ICT solutions).

CRITICAL POLICY:
- 0% Hallucination: The system never fabricates, guesses, or synthesizes fake 
  telephone numbers (+971 50...), fake names, or fake trade licenses.
- Live Ground Truth: Every telephone number, email, and address comes directly 
  from either the company's live official website, Google Places API, Apollo B2B API,
  or official UAE commercial registries.

3. FILE-BY-FILE IMPLEMENTATION BREAKDOWN
--------------------------------------------------------------------------------

1. apps/api/src/services/websiteScraper.ts
   - Implements `scrapeWebsiteContacts(targetUrl)`.
   - Uses `axios` and `cheerio` to fetch the target URL.
   - Searches for internal contact pages (/contact, /contact-us, /about).
   - Extracts all `tel:` tags, `mailto:` tags, regex telephone matches, 
     and PostalAddress schema.
   - Normalizes UAE numbers (+971 4..., +971 2..., 800..., 600...).

2. apps/api/src/services/thirdPartyLeads.ts
   - Implements `searchGooglePlaces(options)` using Google Places Text Search
     and Place Details API.
   - Implements `searchApolloLeads(options)` using Apollo.io Organization Search.
   - Implements `enrichLeadFromWebsite(lead)` which crawls any lead's website
     in real-time to attach missing phone/email.

3. apps/api/src/services/aiLookup.ts
   - Implements `aiCompanyLookup(companyName)`.
   - Connects to Google Gemini with `temperature: 0.0`.
   - Stripped of all fake number generators (`generateUaePhone`, `generateUaeMobile`).
   - Automatically executes `scrapeWebsiteContacts()` on the company website to
     ground the result in live HTML.
   - Implements `unverifiedLookup()` for unknown/fake companies: leaves phone, 
     email, and contacts empty rather than hallucinating.

4. apps/api/src/services/leadScraper.ts
   - Implements `aiFetchLiveB2BLeads(source, options)`.
   - Dispatches requests across 2GIS, YellowPages, LinkedIn, and DED.
   - Automatically prioritizes Google Places API and Apollo if keys are provided.
   - Passes all discovered leads through `enrichLeadFromWebsite()`.
   - Removed previous random license numbers and fake person injections.

5. apps/api/src/routes/companies.ts
   - Added endpoint `POST /api/v1/companies/scrape-website` for direct live 
     URL scraping.
   - Updated `POST /api/v1/companies/ai-lookup` to use the zero-hallucination engine.
   - Modified `POST /api/v1/companies` to make contacts optional (`default([])`)
     so companies can be saved without inventing fake contacts.

6. apps/api/src/routes/sources.ts
   - Removed previous lines that hardcoded "Rashid Al Kaabi, Managing Director"
     into imported leads when contacts were empty.
   - Imports now preserve true verified data.

7. apps/web/src/pages/DataSources.tsx
   - Upgraded search bar to accept BOTH company names (e.g., "Al Naboodah") and 
     direct website URLs (e.g., "https://alnaboodahconstruction.com").
   - Shows live verified badges and data sources in the UI.

4. ENVIRONMENT CONFIGURATION (.env)
--------------------------------------------------------------------------------
To configure or extend external data sources, add the following to `.env`:

# Google Gemini AI (for company intelligence & zero-hallucination structuring)
GEMINI_API_KEY=your_gemini_api_key

# Optional: Google Places API (for 100% verified Google Maps business data)
GOOGLE_PLACES_API_KEY=your_google_places_api_key

# Optional: Apollo.io API (for verified B2B enterprise leads & contacts)
APOLLO_API_KEY=your_apollo_api_key
